
主控使用6280B-SOP8来完成
没有6280B的仿真板，只能用6280的仿真板和6280的工程来实现，最后得到的烧录文件需要用官方的`WRTConverter.exe`来转换成6280B的烧录文件

### 脚位和功能
| 引脚编号 | 名称                            | 功能                                                                                             |
| -------- | ------------------------------- | ------------------------------------------------------------------------------------------------ |
| 1        | vcc                             | -                                                                                                |
| 2        | P15                             | 滚珠检测（外部有上拉，有震动时，检测到高电平，没有震动时，检测到低电平；建议检测时采用边沿检测） |
| 3        | P14                             | 开关，控制笔头ic的供电                                                                           |
| 4        | P13                             | 充电检测                                                                                         |
| 5        | P12 (SCK，仿真时 `不影响` 功能) | LED控制（A端）                                                                                   |
| 6        | P11 (SDI，仿真时 会 受到`影响`) | LED控制（B端）                                                                                   |
| 7        | P10 (SDO，仿真时 会 受到`影响`) | LED控制（按键检测、LED公共端）                                                                   |
| 8        | GND                             | -                                                                                                |

---

### 按键检测
检测按键时，引脚配置为输入上拉，有按键按下时，检测到低电平

### 滚珠（振动）检测
P15 配置为输入模式，并且要**打开内部上拉（20K）**，否则检测不到振动。
采用边沿检测：检测脚电平与上次不同时，清空自动关机的倒计时。

### 笔头供电 

- 实际是用输出低电平来打开笔头供电，输入模式并且关闭上下拉来断开笔头供电

### 充电检测

外部100K下拉，20K上拉，上拉接5V充电口。
到引脚的电压： 5 * 100 / (100 + 20) 约为 4.16V

程序上可以直接检测引脚有没有高电平，来判断是否有充电
